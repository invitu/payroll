Enable the reimbursement globally in *Payroll ‣ Configuration ‣
Settings ‣ Expenses*. Every employee inherits this setting and can be
overridden individually on the employee form (the override is reset
when the company setting changes).

Create a salary rule reading the ``EXP_REIMB`` input (the code of the
provided *Expense Reimbursement* work entry type) and place it where
needed, typically after the net with a positive amount.
